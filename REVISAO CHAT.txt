Sobre real-time tick a tick

Isso é viável mas tem uma implicação arquitetural séria que preciso te contar antes. O Dash no browser comunica via HTTP polling — mesmo com dcc.Interval em 1 segundo, cada atualização é uma requisição HTTP completa. Para tick a tick real (WIN tem ~1300 ticks/segundo na abertura), isso não funciona no browser.

O que funciona de verdade para real-time no MT5 são duas abordagens:

WebSocket com backend Python — o servidor lê ticks do MT5 continuamente e empurra para o browser via WebSocket. Dash suporta isso com dash-extensions ou com um servidor auxiliar.
Atualização a cada novo candle M5 — não tick a tick, mas a cada 5 minutos o candle fecha e o dashboard atualiza. Para análise de price action M5 isso é suficiente e muito mais simples.
A pergunta real é: o que você precisa ver mudando em tempo real? Se for o delta do candle em formação, preço atual, e as métricas do snapshot — isso pode ser feito com polling de 2-3 segundos sem WebSocket, que é simples. Se precisar ver cada tick individual acontecendo, aí é WebSocket.

Sobre o delta — por que importa para você como trader grafista

Delta é a diferença entre o volume que foi executado pelo lado comprador e pelo lado vendedor dentro de um candle. Em termos simples: quem agrediu mais.

No mercado de futuros, cada negócio tem dois lados — um comprador e um vendedor. Mas um deles é o agressor (quem colocou ordem a mercado, aceitando qualquer preço) e o outro é o passivo (quem estava com ordem limitada esperando). O agressor revela intenção real — ele queria entrar agora, a qualquer custo.

Por que isso importa para price action:

Imagine um candle de alta forte, fechando na máxima. Visualmente parece bullish. Mas se o delta for negativo — ou seja, mais volume vendedor do que comprador dentro desse candle — significa que o preço subiu mas quem estava agredindo era o vendedor. Isso é um sinal de fraqueza disfarçada de força. Os compradores estavam sendo absorvidos.

O contrário também vale: candle de baixa com delta positivo (compradores agredindo numa queda) pode indicar absorção — grandes players comprando enquanto o mercado cai, o que frequentemente precede reversão.

No seu operacional concreto:

Build-up com double pressure comprador + tendência de alta = fuga mais provável para cima com qualidade
Candle de rompimento de resistência com delta negativo = rompimento fraco, maior chance de falha
Exaustão de tendência com inversão de delta = sinal antecipado antes do gráfico mostrar reversão
O dashboard não vai te mostrar o número do delta — vai te mostrar a conclusão: "rompimento de resistência com agressão vendedora — qualidade baixa" ou "pullback com absorção compradora — tendência preservada".
